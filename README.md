# ProjetoFinalFrontEnd

## Descrição
Esse é o projeto final da matéria de Front End da Universidade Católica de Salvador (UCSAL)

O grupo do trabalho é o número 1, formado por Arthur Barbosa Bigdêdd e Richard Oliveira de Cerqueira Spinola.
O foco do trabalho é fazer um top 10 de algo desejado pelo aluno. Então decidimos fazer um top 10 de distribuições linux.
